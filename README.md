# SQL Practice Resources

Companion files for **100 SQL Practice Exercises with Solutions** by Rafal Podraza.

## Files

- `sql_practice_lab_mysql8.sql` - MySQL 8 practice database used in the book exercises.

## How To Use

1. Download or clone this repository.
2. Open MySQL 8.0 or 8.4+.
3. Run `sql_practice_lab_mysql8.sql` in a practice environment.

The script recreates the `sql_practice_lab` database, creates the tables, inserts sample data, adds starter indexes, and prints a short success check at the end.
